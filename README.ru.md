# Breeding Robot (OpenComputers + IC2 + Computronics)

**Minecraft:** 1.12.2  
**Mods:** OpenComputers, IndustrialCraft 2 Experimental, Computronics

---

## 📌 Описание
Автоматизированная система селекции, скрещивания и мутации растений из IC2. 
Робот выполняет рутинную работу: сносит сорняки, пересаживает лучшие семена, собирает топовые семена и семена новых видов, защищает поле от агрессивных мутаций (G24 из IC2 Experimental).

### ✨ Основные возможности:
- **Размножение (Breeding):** Автоматически размножает одинокий росток для полноценного скрещивания с помощью двойных жердочек.
- **Отбор (Selection):** Уничтожает слабые, чрезмерно сильные (Excess) и новые виды (если включен режим `destroy` в `config.lua`), пересаживает только лучших кандидатов.
- **Мутация (Mutation):** Сохраняет новые виды и собирает топовые семена, достигшие целевых характеристик.
- **Аварийный режим (Emergency):** При поломке инвентаря робота сервер переходит в режим экстренной очистки поля от угроз.
- **Локализация:** Поддержка русского, английского и японского языков (настраивается в `config.lua`).
- **Веб-интерфейс:** Отрисовка поля, логов и кнопок управления прямо на мониторе.

## 🔧 Сборка оборудования

### Сервер:
- **Серверная стойка.**
- **Сервер 3 тира.**
- **CPU 3 тира.**
- **EEPROM (Lua BIOS).**
- **Компонентные шины** — подберите под вашу сборку. Например, для поля 5x5 может потребоваться 29-32 компонента — это 2 шины 3 тира. 
- **Видеокарта 3 тира.**
- **Память 3/3.5 тира** — должно хватить 1 планки, но лучше не жадничать.
- **Плата беспроводной сети 1/2 тира.** 1 тира хватит с головой, если поле небольшое.
- **Интернет-карта** — для установки софта.
- **Жесткий диск** с установленной OpenOS — любой.
- **Монитор 3 тира.**
- **Клавиатура.**

### Робот:
- **Системный блок 3 тира.**
- **Процессор с видеокартой APU 2 тира.**
- **EEPROM (Lua BIOS).**
- **Память 2/2.5 тира** — 1 шт. хватит.
- **Жёсткий диск 1 тира** с **заранее** установленной OpenOS.
- **Монитор 1 тира.**
- **Клавиатура.**
- **Плата беспроводной сети 1/2 тира.**
- **Улучшение "Инвентарь"** — хватит 1 шт., но можно добавить.
- **Улучшение "Контроллер инвентаря".**
- **Улучшение "Парение" 2 тира.**
- **Контейнер для карты 2 тира** — 1 шт. Для установки интернет-карты, чтобы установить софт.
- **Контейнер для улучшений 2 тира.** Для установки улучшения "Навигация" (улучшение "Навигация" можно просто встроить в робота).
- **Контейнер для улучшений 3 тира.** — по желанию, я ставлю в него аккумулятор 3 тира.
- Остальные очки по желанию можно добить улучшениями **"Инвентарь"** или улучшениями **"Солнечный генератор".**

## 🛠️ Установка

1. Установите **Интернет-карту** в робота и в серверный компьютер.
2. Введите следующую команду в терминале для запуска автоустановщика:

    ```
    wget -f "https://raw.githubusercontent.com/SerGamE/Breeding-robot-OC-IC2-computronics-MC1.12.2-/refs/heads/main/installer.lua" /home/installer.lua && installer
    ```

3. Установщик сам определит, запущен он на роботе или на сервере, и скачает нужные файлы.
4. Следуйте инструкциям в консоли (настройка автозапуска, установка компонентов).

## ⚙️ Настройка (`config.lua`)

| Параметр | Описание |
| :--- | :--- |
| `language` | Язык интерфейса (`"Ru"`, `"En"`, `"Ja"`). |
| `max_growth` | Порог гена Growth, выше которого растение считается агрессивным сорняком (G24). Для классической IC2 поставьте `nil` или `0`. |
| `field_x`, `field_z` | Размеры поля по осям X и Z. |
| `crop_id` | ID культуры, которую скрещиваем (например, `"stickreed"`, `"hops"`, `"wheat"`). |
| `target` | Целевые гены (`{ g = 21, ga = 31, r = 0 }`). |
| `new_species` | Режим работы с новыми видами: `"destroy"` (сносить) или `"save"` (сохранять семена в сундук). |
| `min_dead_parents` | Количество погибших родителей, после которого сервер выходит из режима MUTATION. |

## 🖥️ Управление

- **Кнопка PAUSE** (или клавиша `PAUSE` на клавиатуре) — приостанавливает выдачу задач. Робот доработает текущую задачу, очистит поле от угроз и встанет на зарядник.
- **Кнопка SHUTDOWN** (или клавиша `END`) — безопасное выключение. Сервер дождется, пока робот очистит поле от опасностей (сорняки, пустые жердочки), и завершит работу.
- Управлять кнопками могут только игроки, добавленные в систему компьютера (`computer.users()`).

## 🏗️ Схема постройки и первый запуск

1. Постройте поле, увлажните его блоком воды, вспашите мотыгой.
2. Под полем разместите адаптеры (прямо под грядками или через блок, чтобы можно было ставить руду). 
3. Поставьте жердочку на грядку, кликните по ней ПКМ с МФУ в руке. Должна появиться зеленая голограмма (это значит, что МФУ настроилась). Ломаем жердочку, кладем МФУ в адаптер под этой грядкой. Проделайте это со всеми адаптерами и грядками. 
4. Подключите кабелем адаптеры к серверной стойке, настройте сторону сервера, подключите монитор и клавиатуру, установите софт и настройте `config.lua`.
5. Поставьте зарядник на уровне с жердочками. Робот должен стоять на нем лицом на юг (к полю).
6. Над роботом поставьте Путевую точку, поверните ее ключом лицом вниз и назовите "CHICHI" (или своё название). Если меняете название, то в `r.lua` у робота замените `local WAYPOINT_LABEL = "своё название"`. Там же настраиваются порт, Wake up сообщение и координаты сундуков (если захотите их переместить).
7. Запустите `r.lua`, положите инструменты (жердочки, ваджру/топор, пропалыватель) и нажмите Enter. Робот сохранит список инструментов.
8. Расставьте сундуки относительно зарядника:
- Сундук 1 (слева) — сброс мусора.
- Сундук 2 (справа) — жердочки.
- Сундук 3 (правее) — семена новых видов.
- Сундук 4 (еще правее) — топовые семена.
*Робот должен летать прямо над сундуками и жердочками с растениями.*
9. Убедитесь, что робот включен, экипирован и `r.lua` запущен.
10. На сервере запустите `mapping.lua`. Сервер с роботом создадут карту поля и сохранят её (это делается **всего один раз**).
11. Запустите `server.lua`. На экране отобразится схема поля: тёмно-зеленые клетки — родительские, тёмно-синие — места для скрещивания.
12. Достаточно посадить **одно растение** (если больше, — то в шахматном порядке). Дальше программа всё сделает сама.
